# Pre-existing work disclosure

This repository is a new contest project: **Team unjargon agent**. It was created for the All Things Agentic Hackathon submission period.

The separately maintained, open-source [unjargon.app](https://github.com/Chrisa142857/unjargon.app) inspired the problem area: helping an individual understand jargon in AI-agent work. No code, collector, authentication flow, database, UI, or deployment from that project is included here.

New work in this repository is the Gemini + Google ADK Collaborative Partner, Firestore term-level team memory, FastAPI demo UI, Cloud Run deployment configuration, and the two-member feedback loop. The app deliberately does not import or persist agent transcripts.
